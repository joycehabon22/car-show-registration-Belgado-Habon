# Car Show Registration System

A web-based Car Show Registration System developed as an Integrative Programming 2 final project.

## Project Structure

- `backend/` – C# .NET Web API
- `frontend/` – React frontend
- `docs/` – Project documentation
- `screenshots/` – API testing screenshots

## Technologies Used

- C# / .NET 10
- Entity Framework Core
- SQLite
- FluentValidation
- Scalar
- React
